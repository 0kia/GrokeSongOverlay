Setup Required (Spotify Premium is Required)

Spotify now requires apps using certain API features to be associated with an approved organisation with more than 250,000 monthly active users. Because I do not meet this requirement, you'll need to create your own Spotify Developer app.

It's quick and easy:

  1. Go to developer.spotify.com and log in.
  2. Create a new app.
  3. Name it whatever you'd like. The Redirect URI must be: https://0kia.github.io/OkiaOverlay/pages/callback.html
  4. Go to User Management and add the email address of the Spotify account you'll be logging in with. The name doesn't matter.
  5. Copy the app's Client ID and paste it below.
  6. Click Login with Spotify.
